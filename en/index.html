Banditboard

Claude Code and Antigravity limits · Android, iPhone, Watch, Windows and Mac

Side project

It started on an Android phone forgotten in a drawer, which became an always-on panel on the desk: how much of the 5-hour session and the week is used, when it resets and whether any model is unstable. Today it also runs on iPhone and Apple Watch, and becomes a widget on Windows and Mac. Each model is Racco, a pixel art raccoon that sleeps, sweats and bursts as the limit gets close.

Kotlin with Jetpack Compose on Android and Compose Desktop on Windows. Usage comes from Claude Code itself on the PC, through a hook that runs /usage, with no token on the phone; the pairing key is encrypted with AES-256-GCM and the Android Keystore. Open source, with a website and docs in Portuguese and English.

  • Kotlin
  • Jetpack Compose
  • Compose Desktop
  • Swift
  • AES-GCM · Keystore
  • Pixel art

Senna

My Windows assistant · v1 in Python, v2 in C#

Side project

v1 talked. I called it by name, asked in Portuguese and it got things done: speech recognition, LLM answers (Gemini, Claude and Ollama), synthesized voice and Spotify and Microsoft integrations over OAuth 2.0. About 8,000 lines of Python, and it was heavy: 682 MB of memory, with the animated orb eating 57% of the CPU.

v2 works quietly. In September 2026 I rewrote it in C# with WinUI 3 and dropped what I didn't use. What stayed is a daily panel and Windows notifications for PRs to review, new issues, merges, meetings, reminders, rain and Claude limits. And the memory stayed: Claude Code saves decisions, reasons and where it stopped, and reads it all back in the next session.

  • C#
  • .NET 10
  • WinUI 3
  • SQLite
  • Local API
  • Python (v1)
  • LLMs (v1)

No download. It was made for a single machine: mine. It's here as a build, not as a product.

Símix Ponto Cloud

Web platform · multitenant SaaS

Símix · work

The cloud platform behind the app and the time clocks: workforce time management for companies in many industries, from supermarkets to trucking. It automates time tracking, schedules and days off and the hour bank, with a manager portal and an employee portal, and integrates with certified time clocks and the main payroll systems.
